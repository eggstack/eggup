# Eggup documentation

These guides help consumers choose and use the published Eggup crates.

| Guide | Use it to |
|---|---|
| [Quickstart](quickstart.md) | Run a first local transaction and explore the examples |
| [Choose a crate](crates.md) | Select crates and understand their boundaries |
| [Versions and upgrades](releases.md) | Check published versions and plan an upgrade |

These pages are non-normative. The source defines the public API, the
[`eggup-core` contracts](../crates/eggup-core/docs/domain.md) define transaction
semantics, and [`architecture/`](../architecture/overview.md) explains the
workspace boundaries. Follow those sources if guidance here differs.
